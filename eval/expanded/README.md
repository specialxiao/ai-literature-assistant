# 扩展检索评测集

20 篇原创技术笔记（10 篇中文、10 篇英文）与 100 道人工编写的标注问题。内容为合成参考资料，不是公开论文或真实用户查询。

## 组成

| 查询 → 证据语言 | 可回答题数 |
|---|---:|
| 中文 → 中文 | 20 |
| 英文 → 英文 | 20 |
| 中文 → 英文 | 20 |
| 英文 → 中文 | 20 |
| 无答案问题（中英文各 10） | 20 |

每篇笔记对应 4 道可回答题，包含改写、相似技术区分、精确术语与尾部证据。无答案题询问缺失实验数据、部署信息或私人信息；它们没有对应事实，不能根据常识编造答案。

`questions.jsonl` 中每题包含唯一 ID、查询、证据文件/逻辑页码、精确原文证据、语言类别及 dev/test 标记。Markdown 资料在当前解析器中为单页，标注页码均为 1。数据完整性测试检查标注证据确实存在并能在实际分块后保留。

dev/test 各 50 题，共用同一检索语料；这是同语料下的问题划分，不代表对未见文档的泛化能力。数据用于发现回归，不能因看过 test 失败后反复调参而继续声称是独立测试。

## 运行

先按主 README 安装并下载本地模型，再执行：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_expanded.py
```

脚本在临时评测库中对比 TF-IDF、BM25、本地 E5 与自动级联，不使用应用资料库，不调用云端模型。完整报告默认保存到 `work/expanded-evaluation.json`，包含整体、语言分组、dev/test 指标和每题的来源排名。可使用 `--modes bm25 auto` 只运行部分模式。

已测的基线与失败案例见 [results.md](results.md)。

新版检索的改动、开发集选参与前后对比见 [improvements.md](improvements.md)。

## 指标边界

- 当前每题标注一个来源页，因此 `recall_at_k` 与页级 Hit@k 等价；它不等于检索出了该页上的正确原文。
- `evidence_text_hit_rate` 进一步检查返回块是否包含标注的精确原文；它是严格字符串覆盖指标，不衡量同义证据或答案质量。
- MRR 使用第一个相关页的名次；一页的多个块可能占据多个结果位置。
- 无答案无命中率衡量检索误命中，不是生成模型的正确拒答率。旧 E5 基线阈值为 0，语义路径通常不会返回空结果；新版 MiniLM 的 0.35 阈值在 dev 上选择，仍可能误命中或误拒检。
- 每种模式先进行一次预热，查询延迟不包含这次预热。首次语义预热包含模型冷加载和索引构建，后续模式复用它们，不可直接比较预热耗时。
- 结果仅适用于这份合成语料；真实论文、大规模性能、答案忠实度及幻觉率需要另行评测。
