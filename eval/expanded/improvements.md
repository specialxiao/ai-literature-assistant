# 检索改进结果

日期：2026-10-24。与 [旧基线](results.md) 使用同一份 100 题合成评测集和 20 篇笔记，应用分块仍为 40 块；未修改语料、查询或相关性标注。

数据 SHA-256：`b02e0aa5a11bc208edd07dd99e0edd965512031b0339e3d61811ccdbedae2601`。

## 自动模式前后对比

| 指标 | 旧版 E5 + 级联 | 新版 MiniLM + 级联 |
|---|---:|---:|
| 可回答题页级 Hit@5 / Recall@5（80题） | 50.00%（40/80） | 93.75%（75/80） |
| MRR（80题） | 0.5000 | 0.8013 |
| 跨语言 Hit@5（40题） | 0%（0/40） | 87.50%（35/40） |
| 精确原文证据覆盖率（80题） | 48.75% | 87.50% |
| 无答案无命中率（20题） | 0%（0/20） | 40%（8/20） |

这是整体系统改动的前后对比，不能把提升全部归因于 RRF、阈值或某个单独组件，也不能表述为真实论文场景中的通用提升。

## 具体修改

- 新增本地 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`，仍为 384 维、CPU 推理，按该模型的 128-token 约定进行重叠窗口编码。旧 E5 保留可选，不删除旧文件和数据库。
- 联合编码 E5 前缀与内容，显式正确添加两个模型所需的边界标记；针对新分词器增加与官方短文本编码一致的测试。预处理版本及模型命名空间隔离旧向量缓存。
- 词法置信度只看首块覆盖率，选择性术语必须实际命中；弱词法匹配不强行与语义结果融合。正常推理但没有合格语义证据时返回空；模型异常时仍退回已有 BM25 结果。
- 对同一文档页实行最多两个块的软性优先限制，优先保留来源广度；候选不足时回填，不硬性丢弃同页长文证据。

## 开发集选择与测试子集

通过 `scripts/tune_retrieval.py` 只在 dev 的 50 题上比较两种模型和预定义阈值。选择规则是：优先满足可回答题 Hit@5 至少 90%，再最大化命中率与无答案无命中率的均值。最终选择 MiniLM、阈值 0.35，而不是为提高拒检率牺牲大量可回答题。

| 子集 | 可回答题 Hit@5 | MRR | 无答案无命中率 |
|---|---:|---:|---:|
| dev（40可回答 + 10无答案） | 95.00% | 0.8508 | 50.00% |
| test（40可回答 + 10无答案） | 92.50% | 0.7517 | 30.00% |

test 在上一轮基线分析中已被观察过，并非严格未见盲测集；本轮没有根据 test 指标修改阈值或题目。编码边界缺陷通过独立回归测试发现并修复，再重新执行 dev 选择和最终评测。两个子集共享同一语料，不代表对未见文档的泛化能力。

## 仍存在的限制

- 20 道无答案题仍有 12 道返回片段；正确引用标记和相似度阈值不能代替事实支持核验。
- 完整 80 道可回答题中，页级命中为 75 道，精确原文覆盖为 70 道。召回正确页不代表一定找到了正确段落。
- 本轮只评测检索，没有调用回答模型，因此没有测量正确拒答率、答案忠实度或幻觉率。
- 0.35 只是在此开发集上的经验阈值。切换模型、领域或语料后应重新评测，不应把分数解释为概率。

## 复现

确认 `.env` 使用 `TECHLIT_LOCAL_MODEL=minilm`、对应模型目录和 `TECHLIT_LOCAL_MIN_SCORE=0.35`，按主 README 下载模型，然后执行：

```powershell
.\.venv\Scripts\python.exe scripts/tune_retrieval.py
.\.venv\Scripts\python.exe scripts/evaluate_expanded.py --output work/expanded-improved-final.json
```

完整逐题结果保存在运行生成的 JSON 中。临时评测库与应用库分离，不调用云端 API。66 项自动化测试及界面加载检查通过，包含两个模型的编码约定、长文本尾部、阈值拒检、异常降级与缓存隔离。

模型用法依据：[MiniLM 模型说明](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)、[E5 模型说明](https://huggingface.co/intfloat/multilingual-e5-small)。
