## 暴露的问题

- 此前 8 题小样例的高分不能外推到扩展集。当前实现的跨语言召回明显不足，融合也没有自动带来提升。例如 `en03`（中问英的因果遮罩问题）和 `zh03`（英问中的块编号/页码问题）未检索到标注来源。
- 页级命中不代表正确段落命中。自动模式页级命中率为 50%，精确证据覆盖率仅为 48.75%。
- 自动模式的 20 道无答案题全部存在检索结果，默认排序和融合不能替代证据充分性判断。此处未运行生成模型，不能据此报告正确拒答率或幻觉率。
- 语义模型调用比例为 91%，本次没有语义异常降级。调用比例不等于产生向量 API 费用，本次向量 API 调用比例为零。
