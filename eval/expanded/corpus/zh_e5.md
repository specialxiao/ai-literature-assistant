# 本地 E5 向量编码约定

本地 multilingual-e5-small 使用不同角色的文本前缀。用户问题添加 query: 前缀，文档片段添加 passage: 前缀；即使内容是中文也要遵守相同约定。该模型输出 384 维向量。对编码结果做 L2 归一化后，可以用余弦相似度进行排序。

单次模型输入的上限为 512 tokens，前缀和特殊 token 也包含在预算中。字符数不等于 token 数，因此不能把五百个汉字直接当成五百个 token。长文本应按 tokenizer 结果切成带重叠的窗口，以免直接截断尾部证据。

一个简单实现是先归一化每个窗口向量，再对同一原始块的窗口取平均并重新归一化。这样保持一个块一个向量，便于复用原始页码，但平均可能稀释很短的相关段落。另一个方案是独立索引窗口，再将命中的窗口映射回原始块。两种方案需要分别评测，不能假设任何一种始终更好。
